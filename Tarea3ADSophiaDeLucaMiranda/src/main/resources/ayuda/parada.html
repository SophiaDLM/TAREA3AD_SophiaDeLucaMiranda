Exportar Datos de una Parada

Un usuario del tipo administrador de parada podrá exportar, es decir, ver en pantalla los datos de su parada, incluyendo las estancias realizadas y el nombre del peregrino que las realizó.


Para ello, es necesario que el administrador de paradas introduzca un rango de fechas para buscar las estancias realizadas.

Sellar Carnet de Peregrino

El administrador de parada podrá sellar el carnet de un peregrino si se le proporciona el ID, actualizando la distancia entre las paradas que recorrió y el número de estancias V.I.P. que realizó hasta la fecha.

Ofrecer Alojamiento

Después de sellar el carnet de un peregrino, se le podrá preguntar si desea realizar una estancia. En caso de que la respuesta sea sí, se le deberá preguntar si desea que sea del tipo V.I.P. o no. Si la estancia es V.I.P., se registrará en la base de datos y la próxima vez que se selle el carnet, será actualizado.
